Project Description

This project focuses on analyzing the Zomato restaurant dataset using Python, Pandas, and Matplotlib.

Objectives

* Load and explore the dataset.
* Perform data cleaning and transformation.
* Handle missing values using mean imputation.
* Generate meaningful insights.
* Visualize the results using graphs and charts.

Technologies Used

* Python
* Google Colab
* Pandas
* Matplotlib

Files Included

* Zomato_Restaurant_Analysis.ipynb – Jupyter Notebook containing the analysis and code.
* zomato_cleaned.csv – Cleaned dataset.

Conclusion

The project helps understand restaurant data through data cleaning, analysis, and visualization.
